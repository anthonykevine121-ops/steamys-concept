# Steamy Concepts — Cleaning & Restoration Website

A responsive single-page Next.js website based on the supplied cleaning/restoration design reference.

## Stack
- Next.js 15 / React 19
- TypeScript
- Tailwind CSS
- Lucide React icons

## Getting started

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Customize
- Edit the business name, phone number, service descriptions and offers in `app/page.tsx`.
- Replace the Unsplash image URLs in `app/page.tsx` with your own licensed photography.
- Adjust brand colors in `tailwind.config.ts` and `app/globals.css`.

## Forms
The quote form currently demonstrates client-side submission feedback only. Connect it to an email service, CRM, or API route before using it to receive real customer enquiries.
